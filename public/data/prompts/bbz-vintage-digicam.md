업로드한 이미지를 기반으로 프리미엄 빈티지 디지털카메라 에디토리얼 콜라주 이미지로 재구성한다.

# 1. 절대 규칙 — 원본 이미지 사용 (최우선)

업로드한 원본 이미지는 반드시 **정확히 2번만** 사용한다.

1. 상단 — 빈티지 디지털카메라의 LCD 화면 안
2. 하단 — 메인 에디토리얼 이미지

- 원본 이미지를 2회 이상 반복 사용하지 않는다.
- 업로드 이미지와 유사한 새로운 장면을 추가 생성하지 않는다.
- 반드시 업로드한 동일 원본 장면만 사용한다.
- 하단 메인 이미지는 업로드 원본 이미지 그 자체를 기반으로 사용한다.
- 새로운 인물, 새로운 배경, 유사한 대체 장면을 만들지 않는다.

# 2. TEXT RULES — VERY IMPORTANT

- NO TEXT.
- NO TYPOGRAPHY.
- NO LETTERS.
- NO WORDS.
- NO TITLES.
- NO CAPTIONS.
- NO MAGAZINE HEADLINES.
- NO WATERMARKS.
- NO LOGOS.
- NO SIGNATURES.
- NO HANDWRITING.
- NO DECORATIVE TYPOGRAPHY.
- DO NOT GENERATE ANY ENGLISH WORDS.
- DO NOT GENERATE ANY KOREAN TEXT.
- DO NOT GENERATE ANY RANDOM CHARACTERS.
- DO NOT GENERATE ANY MAGAZINE COVER TEXT.

원칙:

- Any text generation is strictly prohibited.
- Any letters, numbers, symbols, logos, captions, or typography are prohibited.
- Empty editorial negative space is preferred over generated text.
- Leave clean negative space where typography would normally appear.
- The composition should feel like a premium editorial layout without any written elements.
- Use only photography, spacing, balance, light, and composition to create the editorial mood.

# 3. 캔버스 & 레이아웃

- 전체 비율: **9:16 세로** (인스타그램 릴스 비율)
- 구성: 위아래가 명확히 나뉘는 **2분할 구조**
- 분할 비율: **상단 50% / 하단 50%** (정확한 5:5)
- 상단과 하단 사이의 분할은 시각적으로 명확하게 느껴지게 한다.
- 과한 프레임, 두꺼운 테두리, 박스형 구분선은 피한다.
- 깔끔하고 정돈된 프리미엄 에디토리얼 분할감으로 표현한다.

# 4. 상단 영역 — 빈티지 디지털카메라

## 4-1. 카메라 배치

- 실제 2000년대 초반 compact digital camera의 **후면부**가 크게 보이도록 배치한다.
- 카메라는 침구 위에 평평하게 놓인 상태로 표현한다.
- 정면에서 바르게 보이도록 정직한 수평·수직 정렬로 배치한다.
- 카메라 바디가 사선으로 기울어지지 않게 한다.
- 디카는 화면 프레임에 평행하게 반듯하게 놓여 있어야 한다.
- 구도는 탑뷰 플랫레이 느낌이지만, 카메라의 방향은 반드시 정면 정렬로 유지한다.
- 카메라는 상단 패널 가로폭의 약 **60~65% 크기**로 배치한다 (패널을 꽉 채우지 않는다).
- 카메라 위아래와 좌우에 침구 배경 여백을 넉넉하게 남긴다.
- 카메라 바디와 스트랩이 프레임 가장자리에 닿거나 잘리지 않게 한다.

## 4-2. 카메라 디자인

- LCD 화면은 왼쪽, 조작 버튼과 원형 네비게이션 휠은 오른쪽
- 실제 제품 사진처럼 현실적인 구조 (장난감처럼 보이지 않게)
- 2000년대 초반 Canon / Sony / Fujifilm compact digital camera에서 영감 받은 현실적인 디자인
- 샴페인 실버, 웜 실버, 또는 바랜 실버 톤 바디
- 약간 두께감 있는 직사각형 바디, 둥글지만 약간 투박한 모서리
- 플라스틱과 메탈이 섞인 실제 디카 질감
- 오래 사용한 듯한 미세한 스크래치
- 두꺼운 LCD 베젤, 작은 뷰파인더
- 실제 버튼 구조, 원형 네비게이션 휠, 작은 스피커 홀
- 브랜드 로고 없는 깨끗한 바디 (TEXT RULES의 NO LOGOS 적용)

## 4-3. LCD 화면 속 이미지

LCD 화면 안에는 업로드한 원본 이미지를 자연스럽게 넣는다.

- 업로드한 이미지의 핵심 피사체가 잘리지 않게 안전하게 맞춘다.
- 사람, 얼굴, 몸, 손, 주요 오브젝트가 어색하게 잘리지 않게 한다.
- 선명하고 알아보기 쉽게 넣는다.
- 오래된 디카 화면 느낌은 유지하되 너무 뿌옇게 만들지 않는다.
- 약한 픽셀감 + 미세한 화면 노이즈 + 은은한 LCD glow
- 선명하지만 스마트폰 화면처럼 과하게 깨끗하지는 않게 표현한다.

## 4-4. 상단 배경 (침구)

- 깨끗한 호텔 침대 위의 화이트 또는 웜 아이보리 침구
- 자연스럽게 구겨지고 접힌 고밀도 코튼 시트
- 카메라가 실제로 침구 위에 닿아 있는 듯한 접지감과 부드러운 그림자
- 따뜻한 아침 자연광
- 침구 주름을 따라 생기는 부드러운 하이라이트와 그림자
- 조용하고 프리미엄한 호텔 룸의 아침 무드
- 순백색 과노출 금지 — 크림 화이트와 웜 아이보리 톤 유지

# 5. 하단 영역 — 메인 에디토리얼 이미지

- 업로드한 원본 이미지를 **풀블리드**로 크게 사용한다.
- 이미지가 하단 영역 전체를 가득 채우게 한다.

## 5-1. 크롭 규칙 (중요)

- 원본 이미지의 핵심 피사체가 잘리지 않도록 안전하게 크롭한다.
- 특히 사람, 얼굴, 몸통, 다리, 손, 주요 소품, 실루엣 하단부가 어색하게 잘리지 않게 한다.
- 피사체를 너무 타이트하게 확대하지 않는다 — 피사체 주변(특히 위아래)에 배경 여백이 넉넉하게 보이도록 와이드하게 크롭한다.
- 피사체는 하단 패널 중앙에 배치하고, 패널 가장자리에 바짝 붙지 않게 한다.

## 5-2. 원본에서 유지할 요소

- 구도 / 분위기 / 피사체 / 배경 / 빛의 방향 / 핵심 장면

## 5-3. 보정 스타일

- 실제 사진 질감 유지 — 일러스트, 페인팅, 드로잉, 3D 렌더처럼 변환하지 않는다.
- 살짝 바랜 색감, 따뜻한 햇빛, 낮은 콘트라스트
- 은은한 필름 그레인, 약간의 블룸 효과
- 현실적인 빈티지 CCD 디지털카메라 색감
- 과한 광고 보정 금지

# 7. 금지사항 체크리스트

원본 이미지:

- 업로드 원본 이미지를 2번 이상 반복 사용 금지

- 업로드 원본을 바탕으로 한 대체 인물 / 대체 배경 생성 금지
- 하단 핵심 피사체 잘림 금지
- 하단 메인 이미지를 일러스트처럼 변환 금지

텍스트:

- 이미지 내 모든 텍스트, 글자, 타이포, 로고, 워터마크 생성 금지
- 흰색 텍스트 박스 금지
- 배너형 텍스트 금지

카메라:

- 카메라를 사선으로 틀어 배치하는 것 금지

레이아웃 / 장식:

- 과한 스티커, 리본, 체리, 낙서 장식 금지
- 상단과 하단 비율이 흐려지지 않게
- 2분할 구조가 애매하게 섞이지 않게
